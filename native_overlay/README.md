# 游戏内录屏展示（0.3.1）

独立 Mod，通过本机 HTTP 读取控制台日志，不占用 TCP 游戏桥接、不发送游戏动作。

## 气泡与字幕

在未被其他页面覆盖的战斗中，复用游戏自己的 `NSpeechBubbleVfx.Create`，
与多人催促和怪物台词使用同一个原生场景、框体、动画和角色说话锚点。
只创建本地视觉效果，不发多人消息，也不替换游戏自己的台词。

通过 `ActiveScreenContext` 判断当前页面；选卡、地图、卡牌检查、弹窗等页面
覆盖战斗，或当前没有可见角色时，自动改为最上方居中字幕。回到战斗后，
未过期的讲解恢复为原生气泡。也可在菜单中选择始终使用字幕。

长讲解优先按标点和英文单词分页。Alt+F8 的“讲解播放方式”可选择：
- 即时性：新说明直接替换当前说明，切换时也立即清空积压并显示最新说明。
- 可阅读性（默认）：完整说明依序播放，新说明不会打断未读完的页面。

设置即时生效并持久保存，完整日志不受播放方式影响。
取消服务端 600 字硬截断，原文保留在右侧日志中。原生气泡按实际排版测量字号，放不下就回退字幕；字幕不再限制三行。中文使用字体回退，无需切换游戏语言。
气泡/字幕默认保留 20 秒；多页时至少保留到全部页面展示完毕。
断开控制台后仍播完已收到的说明，右侧保留历史并标记断开。
阅读时间取设置和按字数估算时间的较大值；打开设置时暂停翻页。

## Alt+F8 设置菜单

`Alt+F8` 打开/关闭设置，`Esc` 关闭。关闭整个展示层后仍能打开菜单。
原来的 F9–F12 和方向键快捷设置已统一放入菜单，所有设置即时生效并自动保存：

- 展示总开关、讲解开关、自动原生气泡/始终字幕、持续时间、翻页间隔、原生气泡缩放。
- 字幕顶部位置、宽度和字号。
- 右侧面板开关、位置、宽高、字号、文字/背景/异常的不透明度。
- 全部日志 / 决策与计划 / 信息与异常筛选，以及错误、actions JSON、附加字段开关。
- 最近条数（1–2000）、自动跟随最新日志、菜单关闭后是否允许鼠标滚动日志。
- 本机控制台地址和中文/English 讲解语言。

讲解语言保存到控制台，下次启动 Agent 生效；其他展示设置不需要重启。
设置文件为游戏的 `user://agent_overlay.cfg`。菜单不会暂停 Agent 或游戏。

## 完整日志与历史

右侧使用与控制台 `/api/logs` 相同的完整记录，包含正文、动作/计划、执行结果、
状态、检查点、耗时和其他附加字段；不截断单条正文。默认展示最近 40 条，
**最新在最上方**，可滚动看更早内容。关闭自动跟随后，阅读旧日志时不会被新内容推走。

打开设置菜单即可滚动右侧日志；默认关闭菜单后恢复鼠标穿透，避免误拦游戏操作。
可开启“菜单关闭后仍可滚动日志”。记录分批传输，不因一次响应过长而丢弃整条记录。

Mod 本地最多保留 2000 条；首次连接只能补取控制台当前内存中的最多 1000 条。
更早的运行记录仍需看原有 `logs/run_*.jsonl`。服务重启会重置游标和本地历史，
避免旧日志混入新会话。与游戏已有 HP、金币等信息不另做重复统计面板。

异常拟人化文字只是展示层提示；原始异常仍可在右侧日志中查看。
角色讲解使用 `thought` / chunk summary，供应商原始 reasoning 的语言不保证可控。

## 安装与构建

重启更新后的 `server.py`。将 `dist` 内的 `STS2AgentOverlay.dll`、
`STS2AgentOverlay.pck`、`STS2AgentOverlay.json` 放进游戏
`mods/STS2AgentOverlay/`，然后重启游戏。现有 `STS2BridgeMod` 保留。

需要 .NET 9、Godot Mono 4.5.1：

```powershell
./build.ps1 -Sts2DataDir '游戏目录/data_sts2_windows_x86_64' -GodotExe 'Godot控制台程序.exe'
```

脚本只构建 `dist/`，不自动覆盖游戏目录或启动游戏。

## 验证

```powershell
dotnet build -c Debug -p:OverlayPreview=true -p:Sts2DataDir='游戏目录/data_sts2_windows_x86_64'
python preview.py 'Godot控制台程序.exe' --native-pck '游戏目录/SlayTheSpire2.pck'
```

使用合成日志和独立设置目录，验证原生气泡资源、字幕、日志排序/去重、菜单、
设置持久化和服务重启。截图保存在 `dist/preview.png` 和 `dist/settings.png`。
此验证不启动真实对局；战斗锚点与实际选卡页面切换仍需游戏内验收。
